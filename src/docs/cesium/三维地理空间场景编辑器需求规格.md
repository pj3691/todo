# 三维地理空间场景编辑器需求规格

## 1. 项目概述

### 1.1 项目目标

基于 Cesium 构建一个面向三维地理空间数据编辑、管理、分析和场景组织的 Web 编辑器。系统应支持多源空间数据导入、三维对象编辑、底图与地形管理、操作历史记录、图层与对象层级管理，并逐步扩展到专业 GIS 编辑、三维测量、空间分析、协同编辑和工程化发布能力。

### 1.2 目标用户

- GIS 工程师
- 三维场景建模人员
- 城市数字孪生项目人员
- 测绘、规划、应急、交通、水利等行业用户
- 平台运维和数据管理人员

### 1.3 核心定位

系统不是单纯的数据浏览器，而是一个 **三维地理空间场景编辑器**，需要同时具备：

- GIS 数据管理能力
- 三维对象编辑能力
- 场景组织和层级管理能力
- 可视化配置能力
- 工程项目保存、加载和发布能力

---

## 2. 核心功能模块

功能优先级建议分为：

- **P0：基础必需功能**
- **P1：专业编辑能力**
- **P2：高级 GIS / 三维能力**
- **P3：平台化与协作能力**

---

# P0：基础必需功能

## 2.1 项目与场景管理

### 功能说明

支持创建、保存、加载和管理一个三维地理空间编辑项目。

### 功能需求

- 新建项目
- 打开已有项目
- 保存项目
- 另存为项目
- 项目元数据管理：
  - 项目名称
  - 坐标系
  - 默认相机视角
  - 默认底图
  - 默认地形
  - 创建时间
  - 修改时间
  - 创建者
- 场景状态保存：
  - 图层状态
  - 对象层级
  - 对象属性
  - 样式配置
  - 相机位置
  - 时间轴状态
- 自动保存
- 项目恢复
- 最近打开项目列表

---

## 2.2 数据导入功能

### 功能说明

支持导入多种空间数据和三维模型数据，并转换为 Cesium 可渲染的数据结构。

### 支持格式

#### 矢量数据

- GeoJSON
- KML / KMZ
- Shapefile
- CSV / Excel 经纬度点数据
- WKT / WKB
- GPX

#### 三维模型

- GLB / GLTF
- OBJ
- FBX，可通过服务端转换
- 3D Tiles
- CityGML，可通过转换流程接入

#### 点云数据

- LAS / LAZ
- PCD
- PLY
- E57，可作为扩展格式

#### 栅格数据

- GeoTIFF
- DEM
- DSM
- DOM
- 栅格瓦片服务

### 功能需求

- 本地文件上传
- URL 远程加载
- 拖拽导入
- 批量导入
- 导入前格式检测
- 导入进度显示
- 导入失败提示
- 坐标系识别与转换
- 大文件分片上传
- 后端异步转换任务
- 导入完成后自动生成图层
- 导入数据预览
- 导入字段映射
- 数据属性表查看

### 专业要求

- 支持 WGS84、CGCS2000、Web Mercator、地方投影坐标系
- 支持 EPSG 编码选择
- 支持单位识别：
  - 米
  - 度
  - 英尺
- 支持高度模式：
  - 贴地
  - 绝对高度
  - 相对地形高度
  - 相对模型高度

---

## 2.3 底图管理功能

### 功能说明

支持切换、叠加和配置不同类型的底图和地形服务。

### 底图类型

- 影像底图
- 矢量瓦片底图
- 地形服务
- 倾斜摄影
- 3D Tiles 城市模型
- 自定义 WMS / WMTS / XYZ / TMS 服务
- ArcGIS MapServer / ImageServer
- 天地图、高德、百度、Mapbox、自建瓦片服务

### 功能需求

- 添加底图服务
- 删除底图服务
- 启用 / 禁用底图
- 调整底图顺序
- 调整透明度
- 设置最大 / 最小缩放级别
- 设置服务 Token
- 设置服务请求参数
- 地形开关
- 深度检测开关
- 地形夸张系数
- 海洋、水面、天空盒配置
- 底图收藏和分组

---

## 2.4 场景对象管理

### 功能说明

提供类似 3ds Max / Blender 的对象管理方式，支持对三维场景中的对象进行创建、选择、编辑、分组和层级管理。

### 对象类型

- 点
- 线
- 面
- 多边形
- 标签
- Billboard
- 三维模型
- 点云
- 3D Tiles
- 体对象
- 道路
- 管线
- 建筑
- 设备
- 自定义业务对象

### 功能需求

- 对象树管理
- 图层管理
- 对象分组
- 父子层级结构
- 对象锁定
- 对象隐藏 / 显示
- 对象重命名
- 对象复制
- 对象删除
- 对象多选
- 对象搜索
- 对象过滤
- 对象标签
- 对象收藏
- 对象属性面板
- 对象右键菜单
- 对象定位
- 对象包围盒显示
- 对象引用关系查看
