# GitStatus 桌宠桌面版（Windows）

把现有的网页桌宠装进一个覆盖所有显示器组成的虚拟桌面的透明置顶层里，桌宠可以直接从主屏拖到副屏。后端、接口、角色素材和气泡样式完全复用当前项目，桌面端只负责窗口与鼠标交互。

## 运行前提

- Windows 10 / 11
- Node.js 18+
- 后端已经在运行，默认地址 `http://localhost:30012`

## 启动

在项目根目录先用原来的方式启动后端：

```powershell
npx tsx src/index.ts
```

再开一个终端启动桌宠：

```powershell
cd desktop
npm install
npm start
```

也可以在仓库根目录执行：

```powershell
npm run desktop:install
npm run desktop
```

第一次启动时桌宠是未登录状态，会自动弹出登录气泡：

1. 点击气泡里的“去登录喵”；
2. 在登录窗口里登录；
3. 登录成功后桌宠会自动刷新。

如果气泡已经自动收起，点击桌宠右上角的菜单按钮也能重新打开完整面板。

登录状态保存在 Electron 的本地会话里，隐藏到托盘再打开不需要重复登录。

## 交互说明

- 桌面端是一个覆盖所有显示器虚拟桌面的透明覆盖层，只有桌宠和气泡区域会接收鼠标，其他区域直接点击穿透到桌面。
- 按住桌宠可以直接从主屏拖到副屏，位置会自动保存。
- 设置面板里的“显示器”下拉，或托盘右键菜单的“显示器”子菜单，可以快速把桌宠跳到指定屏幕右下角；选择会记住。
- 桌宠右上角的菜单按钮和“+”按钮默认隐藏，鼠标移到桌宠上才显示；触屏设备没有 hover，会保持显示。
- “+”会打开待办页并直接弹出新建待办窗口：桌面版在应用内打开并复用当前登录态，网页版跳转到待办页的 `?add=1`。
- 桌面版所有“打开待办”入口（设置、摘要、托盘）默认在应用内窗口打开，不再跳系统浏览器。
- 待办页内嵌的桌宠默认隐藏，可在账号信息卡片的“待办页桌宠”开关里打开；桌面覆盖层上的桌宠仍由托盘/桌宠设置控制。
- 左键桌宠显示小气泡；右上角菜单按钮打开完整提醒/设置面板。
- 完整气泡右上角的 × 和底部的“隐藏桌宠”都是收进托盘，不是彻底退出；托盘的单击可以显示/隐藏，右键菜单提供显示/隐藏、打开待办和退出。
- 隐藏和回来时小气泡会随机播报“老大下次再见喵”“老大我又回来了喵”等文案。
- 设置面板底部有“隐藏桌宠”（收进托盘）、“打开待办”（在应用内窗口打开）和“退出桌宠”（彻底退出）。退出桌宠不会关闭后端。
- 提醒间隔、上下班提醒、截止前提醒、角色素材、镜像和提醒音都在气泡里的设置面板中，和网页端一致。

## 后端地址

默认连接 `http://localhost:30012`，可以在 [config.json](./config.json) 里修改：

```json
{
  "serverUrl": "http://localhost:30012"
}
```

也可以用环境变量临时覆盖：

```powershell
$env:GITSTATUS_URL = "http://192.168.1.10:30012"
npm start
```

## 打包

```powershell
cd desktop
npm run dist
```

生成的可执行文件在 `desktop/dist/` 下（portable 单文件）。打包需要联网下载 Electron 运行时。

## 代码结构

| 文件 | 作用 |
| --- | --- |
| `main.js` | 创建透明覆盖层、点击穿透、托盘显示/隐藏、隐藏/回来播报、登录窗、新建待办窗、离线重试 |
| `preload.js` | 向页面暴露最小化的窗口控制 API |
| `tray.png` | Windows 托盘图标 |
| `offline.html` | 后端未启动时的重试页 |
| `../src/pages/desktop-pet.html` | 桌面版渲染页，直接加载现有 `pet-widget.css/js` |
| `../src/pages/desktop-login.html` | 桌面版登录页，登录态与网页端共用 localStorage |
| `../src/pages/assets/js/pet-widget.js` | 新增 `desktop` 模式、右上角“+”新建待办、隐藏/回来小气泡、显示器切换、登录回调 |
| `../src/pages/assets/js/pet-preference.js` | 账号信息卡片里的“待办页桌宠”开关 |
| `../src/pages/todo.html` | 支持 `?add=1` 直达新建待办弹窗；网页桌宠默认隐藏 |

## 已知限制

- 目前只做 Windows；点击穿透依赖 Electron 在 Windows 上的 `setIgnoreMouseEvents(..., { forward: true })`。
- 覆盖层覆盖所有显示器组成的虚拟桌面，桌宠可以直接拖到副屏；不同显示器分辨率/缩放差异较大时，位置可能略有偏差。
- 隐藏到托盘后应用仍在后台运行，提醒轮询不会停；彻底退出请用托盘菜单或设置里的“退出桌宠”。
- 后端没有启动时，桌宠窗口会显示重试页；启动后端后点“重新连接”即可。
- 桌面版不会自动启动后端，需要先手动运行项目原有的启动命令。
