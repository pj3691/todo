# 云存储方案与成本说明（个人博客 + Todo）

> 适用项目：GitStatus 个人博客 + Todolist  
> 访问场景：主要使用国内网络  
> 图片上传方式：粘贴即上传（方案 A）  
> 价格基准：2026 年 10 月公开刊例价，实际以云厂商官网为准

---

## 1. 结论摘要

- 推荐使用 **阿里云 OSS 标准存储**：公开桶存博客图片，私有桶存 Todo 图片和附件。
- 博客 Markdown 和 SQLite 数据库继续放在本地，只把图片、附件放进对象存储。
- 个人规模（10~50 GB 图片、每月 20~50 GB 流量）走 CDN 月成本约 **5~20 元**，直出约 **11~31 元**；即使不做压缩和 CDN，通常也在 30 元/月上下。
- 成本大头是 **公网下行流量**，不是存储容量。图片压缩、WebP/缩放、CDN 是三个最有效的降本手段。
- 不建议为 10 GB 数据购买 500 GB 存储包，也不建议把在线图片放进归档存储。
- 建议设置 **50 元/月** 的费用告警，超过时检查图片体积、流量来源和是否被防盗链。

## 2. 推荐方案

| 项目 | 选择 |
|---|---|
| 对象存储 | 阿里云 OSS 标准存储（已有腾讯云资源可等价换 COS） |
| 博客图片 | 公开桶 `gitstatus-blog-public`，公共读、私有写 |
| Todo 图片/附件 | 私有桶 `gitstatus-todo-private`，签名 URL 访问 |
| 博客 Markdown | 继续放 `src/docs`，不搬 |
| SQLite | 继续放本地，每日备份到私有桶 |
| 图片上传 | 编辑器粘贴时自动上传，Markdown 中直接写入 URL |
| CDN/域名 | 有备案域名就绑 `img.example.com` + CDN；没有就先用 OSS 默认域名 |

整体链路：

```text
写博客（Typora / 网页编辑器）
  └─ 粘贴图片 → 自动上传 → OSS 公开桶 → 返回图片 URL → 插入 Markdown

Todo
  ├─ 图片 → 后端 → OSS 私有桶 → 302 签名 URL
  └─ 附件 → 后端 → OSS 私有桶 → 302 签名 URL（下载）

本地
  ├─ src/docs/*.md
  ├─ src/output/gitstatus.db
  └─ 每日备份 → OSS 私有桶 backups/
```

## 3. 价格构成与单价

月成本可以按下面的公式估算：

```text
月成本 ≈ 存储容量(GB) × 存储单价
       + 公网下行流量(GB) × 流量单价
       + 请求费
       + 图片处理费
       + CDN 费用
       + 备份存储费
```

### 3.1 阿里云 OSS 主要单价

| 计费项 | 单价 | 说明 |
|---|---|---|
| 标准存储（本地冗余） | 0.12 元/GB/月 | 在线图片、附件首选 |
| 低频访问存储 | 0.08 元/GB/月 | 最低存 30 天，取回另收费 |
| 归档存储 | 0.033 元/GB/月 | 最低存 60 天，取回慢且收费 |
| 冷归档存储 | 0.015 元/GB/月 | 最低存 180 天 |
| 深度冷归档 | 0.0075 元/GB/月 | 最低存 180 天，适合长期冷备 |
| 公网下行流量（忙时） | 0.5 元/GB | 从 OSS 直接下载到公网 |
| 公网下行流量（闲时） | 0.25 元/GB | 约 0~8 点，适合批量任务 |
| CDN 回源流量 | 0.15 元/GB | OSS 作为 CDN 源站时 |
| 请求费 | 约 0.01 元/万次 | 个人量级通常不到 1 元/月 |
| 图片处理 | 10 TB/月以内免费 | 按处理的原图量计费，超出后 0.025 元/GB |

> 同城冗余存储单价约 0.15 元/GB/月，个人博客用本地冗余即可。

### 3.2 存储包与按量付费

| 规格 | 年付价格（参考） | 折合月价 | 适合场景 |
|---|---|---|---|
| 500 GB | 约 531 元/年 | 约 44 元/月 | 按正常价约 369 GB 后考虑；促销价另算 |
| 1 TB | 约 1087 元/年 | 约 91 元/月 | 数据接近 1 TB |
| 2 TB | 约 2175 元/年 | 约 181 元/月 | 大型图片库 |
| 5 TB | 约 5437 元/年 | 约 453 元/月 | 不适合个人博客 |

说明：

- 年包折算约 0.0885 元/GB/月，比按量 0.12 元便宜约 25%。
- 但存储包是预付费，买大了会浪费。按正常 531 元/年计算，**500 GB 年包的盈亏平衡点约为 369 GB 实际用量**；若遇到约 119 元的限时促销，平衡点才降到约 83 GB。低于平衡点按量付费更划算。
- 阿里云偶尔有 500 GB 年包约 119 元的促销，属于限时活动，不应作为长期预算基准。

## 6. 低成本配置建议

| 措施 | 做法 | 预计效果 |
|---|---|---|
| 上传前压缩 | 图片转 WebP/AVIF，长边限制 1600~2000 px | 体积降低 50%~90% |
| 按需缩放 | OSS 图片处理 `resize,w_1600`，列表用 `w_480` | 流量降低 30%~70% |
| 使用 CDN | 有备案域名后绑定 CDN，缓存图片 30 天 | 流量单价从 0.5 降到约 0.2 元/GB |
| 后端走内网 | 后端与 OSS 同地域时用 internal endpoint | 服务端上传流量免费 |
| 内容哈希去重 | 相同图片只存一份 | 节省 5%~15% 存储 |
| 生命周期清理 | 清理未完成分片、旧版本、回收站 | 节省 5%~20% 存储 |
| 防盗链 | OSS/CDN 配置 Referer 白名单 | 避免外部站点盗刷流量 |
| 不提前买大包 | 存储超过约 369 GB 再考虑 500 GB 年包（促销价另算） | 避免预付费浪费 |
| MD/SQLite 留本地 | 只把图片、附件放 OSS | 避免小文件最低计费和额外请求 |
| 备份只备必要数据 | SQLite + MD，不备份整个 OSS 桶 | 备份成本接近 0 |

### 6.1 图片压缩是第一位

一张 5 MB 的手机照片，压缩到 300 KB 的 WebP 后：

- 存储降低约 94%；
- 用户加载流量降低约 94%；
- 1000 张图片从 5 GB 降到约 0.3 GB。

这比换云厂商、买存储包有效得多。

### 6.2 CDN 什么时候开

建议满足以下任一条件再开 CDN：

- 每月公网流量超过 30~50 GB；
- 图片加载速度明显慢；
- 有已备案域名，愿意配置 HTTPS 和缓存。

流量很小时，OSS 直出更简单，CDN 的配置和备案成本不划算。

### 6.3 不要把钱花在这些地方

- 为 10 GB 数据买 500 GB 存储包；
- 把在线博客图片放归档存储；
- 为个人博客开跨区域复制；
- 用公网直出承载大流量而不做压缩；
- 自建 MinIO/NAS（个人规模运维成本更高）。

## 7. 存储类型怎么选

| 类型 | 单价 | 最低存储 | 取回费 | 适合 |
|---|---:|---|---|---|
| 标准存储 | 0.12 元/GB/月 | 无 | 无 | 在线博客图片、Todo 图片/附件 |
| 低频访问 | 0.08 元/GB/月 | 30 天 | 有 | 很久不看的旧图片、旧附件 |
| 归档存储 | 0.033 元/GB/月 | 60 天 | 有，直读约 0.38 元/GB | 不再上线的旧版本、冷备份 |
| 冷归档 | 0.015 元/GB/月 | 180 天 | 有 | 长期冷备 |
| 深度冷归档 | 0.0075 元/GB/月 | 180 天 | 有 | 合规归档，几乎不读取 |

建议：

- 博客图片、Todo 图片、附件：**标准存储**；
- 旧原图、历史附件：可以转低频；
- 只有确定不再访问的冷数据才转归档；
- Markdown 文件继续放本地/Git，不要放对象存储的低频或归档类型（小文件有 64 KB 最小计费单位）。

## 8. 隐藏费用与注意事项

1. **归档不是免费午餐**：归档存储有最低存储时长，提前删除会补收费用；取回也按 GB 收费。在线图片不要放归档。
2. **低频也有最低存储时长**：OSS 低频最低 30 天，不足 30 天删除会补收。
3. **小文件最小计费**：低频/归档类型单个文件不足 64 KB 按 64 KB 计费，大量小文件不划算。
4. **跨区域复制**：会产生额外存储和流量费用，个人博客不建议开启。
5. **版本控制会占空间**：开启后每次覆盖都会保留旧版本，要配生命周期清理旧版本。
6. **未完成的分片上传**会持续计费，务必配置“7 天未完成分片自动清理”。
7. **CDN 也有费用**：HTTPS 请求、缓存刷新、回源流量都可能收费；CDN 不是完全免费。
8. **域名和备案**：域名约 30~100 元/年；SSL 证书通常有免费额度；大陆 CDN 绑定自定义域名需要 ICP 备案。
9. **免费额度会过期**：腾讯云 COS 新用户 50 GB 免费 6 个月，到期后按量计费；不要把免费额度当长期容量。
10. **价格会变**：以上为 2026 年 10 月刊例价，促销、汇率、地域都会影响实际账单，下单前以官网为准。
11. **公网出口**：如果后端不在阿里云同地域，服务端上传到 OSS 可能走公网；同地域 ECS 用内网 endpoint 可避免这部分流量费。
12. **防盗链**：公开桶建议配置 Referer 白名单，允许空 Referer，避免被其他网站盗刷图片流量。
13. **图片处理 URL**：使用 `?x-oss-process=...` 时，CDN 缓存 key 必须包含查询参数，否则不同尺寸的图片会互相覆盖。

## 9. 不同规模的升级路径

| 规模 | 建议配置 | 预计月成本 |
|---|---|---|
| 图片 < 10 GB，流量 < 20 GB | OSS 标准 + 默认域名，暂不开 CDN | 1~12 元 |
| 图片 10~50 GB，流量 20~50 GB | OSS + 图片压缩 + CDN（有备案域名） | 5~20 元 |
| 图片 50~200 GB，流量 50~200 GB | OSS + CDN + 生命周期 + 存储包（按正常价约 369 GB 再买，促销价另算） | 17~70 元 |
| 图片 > 200 GB | 年包 + 低频分层 + CDN 流量包，定期清理无用图片 | 60~300 元（取决于容量和流量） |
| 海外访问为主 | R2 或 B2 + Cloudflare，出口免费 | 通常低于国内方案 |
| 内网/离线使用 | NAS/MinIO + 异地备份 | 硬件一次性成本 + 运维 |

对个人博客来说，大部分时间会停留在前两档，不需要复杂的存储分层。

## 10. 预算与监控

建议设置三条线：

| 项目 | 建议值 |
|---|---|
| 正常月预算 | 10~30 元 |
| 费用告警 | 50 元/月 |
| 异常检查 | 单日流量超过月均值的 3 倍 |

每月检查：

- 存储总量是否异常增长；
- 公网下行流量主要来自哪些图片；
- CDN 缓存命中率是否正常；
- 是否有未压缩的大图；
- 是否有外部站点盗链；
- 是否误开了版本控制、跨区域复制或归档取回；
- 存储包是否快到期、是否有更合适的规格。

## 11. 最终建议

如果目标是“价格不要太高”，推荐的组合是：

```text
阿里云 OSS 标准存储
  ├─ 公开桶：博客图片
  ├─ 私有桶：Todo 图片、附件、备份
  ├─ 粘贴即上传，不手动传图
  ├─ 上传前压缩为 WebP，长边 1600~2000 px
  ├─ 展示时用 OSS 图片处理缩放
  ├─ 有备案域名后再上 CDN
  └─ 设置 50 元/月费用告警
```

预期成本：

- **10 GB 图片 + 每月 20 GB 流量：约 5~11 元/月；**
- **50 GB 图片 + 每月 50 GB 流量：约 17~31 元/月；**
- **100 GB 图片 + 每月 100 GB 流量：约 34~62 元/月。**

对个人博客 + Todo 来说，这个成本已经足够低；真正需要控制的不是存储单价，而是**图片体积**和**公网流量**。
