## 阅读建议

**只想跑起来** → 主 [README](../README.md) 的[三、网页端启动](../README.md#三网页端启动)或[五、桌面端启动](../README.md#五桌面端electron-桌宠启动)。

**想知道某个页面怎么用** → 先看主 [README 的界面速览](../README.md#界面速览)认个脸，再进 [页面说明/](./页面说明/通用交互与登录.md) 下的六篇文档，每篇都是字段、按钮、交互、限制加常见问题；主 [README 的四、页面使用说明](../README.md#四页面使用说明) 只是导览。

**第一次部署、要给同事开账号** → 先看 [通用交互与登录](./页面说明/通用交互与登录.md)（注册与审核流程、角色怎么选），再看 [账号管理](./页面说明/账号管理.md) 与 [数据共享](./页面说明/数据共享.md)。

**要接接口** → [后端API说明.md](./后端API说明.md)，建议先看：

- [通用约定](./后端API说明.md#一通用约定)：基础地址 `/gitstatus/api`、`res` 包裹格式、JWT 认证、三级角色权限矩阵；
- [本机限定接口](./后端API说明.md#本机限定接口)：哪些接口只能从 loopback 调用（附件用默认程序打开、端口排查、结束进程、一键启动后台等）。

**要改桌宠** → [桌面端使用说明.md](./桌面端使用说明.md) 的[窗口与架构](./桌面端使用说明.md#三窗口与架构)、[代码结构](./桌面端使用说明.md#十代码结构)、[调试](./桌面端使用说明.md#十一调试)。
